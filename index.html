📖 MCJS 介绍

MCJS 是什么？在一台临时的电脑上想快速体验 MC？打开 MCJS，不用下载 Java / 启动器 / 客户端，不需要繁琐的配置操作，打开网页就能玩！

名字：MCJS，即 MC in JavaScript，代表用 JavaScript 运行的 WebMC。

历史：2022 年，Eaglercraft 发布，不同于其他"自制"的网页版 MC，它是第一个最接近于原版的网页版 MC。刚发布时热度很高，但只有英文版，对国内玩家不友好。于是我们启动 MCJS 项目，对原版一行一行翻译，实现了最完整的网页版 MC 中文版。当年很多托管网站满屏广告、加载缓慢，而 MCJS 放弃收益，承诺永远免费且无广告。从 1.8.8 JS 时代到今天的高版本 WASM 时代，我们一直坚持首发新版中文翻译。

注：MCJS 仅为 Eaglercraft 开源项目的中文汉化分支，非原作者，与 Eaglercraft 官方没有从属关系，游戏反馈请找原作者。

🔧 Eaglercraft 介绍

Eaglercraft 由 Eaglercraft 开发团队制作，是在 JavaScript 上运行的网页版 MC，基于 MCJE。使用 TeaVM 和 OpenGL 模拟器运行与浏览器完全兼容的 Java 虚拟机，是众多网页版 MC 开源项目中完成度最高的，支持 MC 的几乎全部特性。

JS 和 WASM 版区别：传统 JS 版可在大多数设备上运行，稳定但性能受限；WASM 是较新技术，帧数更高、延迟更低，但需要电脑端最新 Chrome 支持（部分移动设备现已支持）。浏览器支持的话，WASM 版最推荐。所有高版本强制使用 WASM。

❓ 常见问题（FAQ）

问1：正版官网网址

https://mcjs.link 是 MCJS 唯一官方网站。授权域名：mcjs.link（唯一官网）、mcjs.cc 与 mc.js.cool（旧网址，会跳转至官网）、144449.xyz（CDN 镜像）、mcjs-r2.pages.dev（合作伙伴镜像）。除此之外的任何域名均为未经授权。请勿从搜索引擎搜索，直接在地址栏输入 mcjs.link，域名非官方请立刻退出！

问2：以前的网站被劫持到"反诈"页面

MCJS 绝对不是诈骗网站！本站是纯静态 HTML 网站，不会收集或上传任何用户信息，永久免费不收费。旧站无法访问是因部分用户滥用服务且被恶意举报，导致运营商 DNS 劫持。解决方法：切换到一个能用的镜像站，所有镜像站内容相同，可跨镜像站联机。

问3：游戏存档消失

本类站点仅用于在临时电脑（学校机房、摸鱼等）快速体验，非长期方案。受浏览器缓存限制，存档可能随时被自动删除（浏览器行为，无法干预）。长期游玩请偶尔备份存档，或导出至正版客户端。

问4：游戏打不开 / 卡顿 / 崩溃

请用最新版 Google Chrome，尽量不用其它浏览器；设备优先用电脑而非手机。性能不佳时优先选低版本 + WASM 版，版本越低越流畅。高版本仅推荐高性能电脑运行（只有 WASM 版）。

问5：多人游戏联机问题

支持局域网和远程联机。启用方法：将首选中继服务器设为 wss://relay.mcjs.link。官方 1.8.8(WASM) 客户端已内置并默认首选，无需改动；其它客户端需手动填写，否则可能无法联机。禁止滥用：不公开私有邀请码、不加入未知服务器、不托管大型服务器、不从事任何商业行为。

问6：手机、平板等触屏设备支持

网页版 MC 主要为电脑端设计，有且只有 1.8.8 及部分其它版本能在移动触屏设备运行，其余版本不提供支持。有电脑请优先用电脑，电脑端全版本支持。

问7：更多新版本是否支持

会第一时间同步原作者更新。测试版不稳定、bug 多，仅作体验，bug 请勿反馈。高版本对性能要求高，只有 WASM 版，需高性能电脑 + 支持 WASM 的新版 Chrome，否则会崩溃。

问8：离线游戏文件下载问题

版本更新频繁，离线文件很快过时。为保证大家统一使用最新版本、提升联机兼容性，暂不提供离线下载。各个「开始游戏」按钮均指向在线页面。
